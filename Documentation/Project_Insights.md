Hospital Performance Analytics – Project Insights


Project Overview
This project analyses hospital admission data using SQL and Power BI to understand patient admissions, department performance, discharge rates and monthly admission trends.

Key Findings

Total admissions analysed: 600
Total discharged patients: 540
Currently admitted patients: 60
Discharge rate: 90%
Dataset period: January to December 2025

Department Analysis

General Medicine recorded the highest number of admissions with 123 patients, followed by Cardiology with 112 admissions.

Monthly Trend Analysis

July recorded the highest admissions with 60 patients, while December recorded the lowest with 40 patients.

Tools Used

Microsoft Excel – Data cleaning
MySQL – Data storage and SQL analysis
Power BI – Dashboard visualization


Conclusion

The project demonstrates data cleaning, SQL querying, KPI calculation, department-level analysis, patient admission trends and healthcare data visualisation.
