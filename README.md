# 🏥 Hospital Performance Analytics – 2025

## Project Overview
This project analyses hospital admission data to understand patient admissions, department performance, discharge status, admission trends, and Length of Stay (LOS).

The project uses Excel for data cleaning, MySQL for database management and SQL analysis, and Power BI for interactive dashboard development.

## Objectives
- Analyse total hospital admissions and unique patients.
- Evaluate department-wise admission performance.
- Analyse monthly admission trends.
- Monitor discharge rate and admission status.
- Compare Elective and Emergency admissions.
- Analyse Average Length of Stay (LOS).
- Support hospital operational planning through data-driven insights.

## Tools & Technologies
- **Microsoft Excel** – Data Cleaning
- **MySQL** – Database Management
- **SQL** – Data Analysis
- **Power BI** – Dashboard & Data Visualization

## Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Admissions | 600 |
| Total Patients | 300 |
| Discharged Patients | 540 |
| Discharge Rate | 90% |
| Admitted Admissions | 60 |
| Average Length of Stay | 7.58 days |

## Key Insights
- General Medicine recorded the highest number of admissions (123).
- Cardiology recorded 112 admissions.
- Orthopedics recorded 96 admissions.
- July recorded the highest monthly admissions (60).
- December recorded the lowest monthly admissions (40).
- Elective admissions: 339 (56.5%).
- Emergency admissions: 261 (43.5%).
- Emergency admissions had a higher average LOS (7.87 days) than Elective admissions (7.36 days).

## Power BI Dashboard
The dashboard includes:
- KPI Summary
- Admissions by Department
- Monthly Admission Trend
- Admission Status Distribution
- Admissions by Admission Type
- Department-wise Admission Type Comparison

## Business Recommendations
- Review staffing and bed allocation in high-admission departments.
- Monitor emergency admissions and resource requirements.
- Use monthly admission patterns for operational planning.
- Investigate prolonged Length of Stay.
- Improve department data completeness and validation.
